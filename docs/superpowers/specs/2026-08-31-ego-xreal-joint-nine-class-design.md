# Ego–Xreal 九分类联合训练设计

## 目标

使用 Ego-Exo4D 的七个原始活动类别，加上 Xreal 的 `PUT_ON` 和
`TAKE_OFF` 两个事件类别，端到端训练一个九分类 EgoCHARM 模型。

类别顺序固定为：

1. Basketball
2. Soccer
3. Dance
4. Rock Climbing
5. Cooking
6. Bike Repair
7. Music
8. PUT_ON
9. TAKE_OFF

Xreal 的稳定 `WORN` 和 `NOT_WORN` 不进入九分类训练；它们只用于检查模型
是否把普通佩戴或未佩戴扰动误报成摘戴事件。

## 信号定义

- 每个样本窗口为 5 秒。
- 统一采样率为 200 Hz，因此单个输入包含 1000 个采样点。
- 通道顺序固定为加速度 XYZ、角速度 XYZ。
- 不进行除以 9.8 的归一化。
- Ego `imu-left` 和 Xreal 均只做方向旋转，不使用平移。
- Ego 使用每个 VRS 中的 `T_Cpf_ImuLeft` 旋转到 CPF。
- Xreal 从右、上、后旋转到左、上、前，使用 `diag(-1, 1, -1)`。
- 两种设备都使用 polyphase 抗混叠滤波，统一降采样到 200 Hz。

## 缓存与切窗

Ego 连续录制以 float32 `.npy` 保存，并在 JSON 清单中保存连续片段边界。
训练时以 memory map 读取，不提前展开 964 万个窗口。训练候选窗口的起点
间隔为 25 ms，即 200 Hz 下 5 个采样点。

Xreal 摘戴录制各产生一个居中的 5 秒窗口，同样保存为 float32 `.npy`。
两个日期的数据合并，沿用按录制文件进行的 7:1:2 train/val/test 划分，避免
同一次录制泄漏到多个 split。

## 训练抽样

每个训练 epoch 对九类做均衡随机抽样，每类 3600 个窗口，共 32400 个样本。
Ego 类别按该类所有合法起点均匀抽样；Xreal 事件类别从训练录制中有放回抽样。
Xreal 样本数量很少，因此必须把“每轮重复次数”视为优化采样，而不是新增的
独立数据。

验证集使用固定、可复现的有限索引，不对全部 25 ms 高重叠窗口穷举，模型选择
指标为九分类 macro-F1。

## 训练增强

增强只用于训练集，且保持加速度和角速度的通道语义：

- 每个窗口添加六轴常量偏置；加速度和角速度分别配置范围。
- 绕 XY 平面随机轴施加小角度三维旋转，同时旋转加速度和角速度。
- 分别向加速度和角速度添加逐采样高斯噪声。

默认采用保守幅度：加速度偏置 0.2 m/s²、角速度偏置 0.02 rad/s、倾斜角
5°、加速度噪声标准差 0.05 m/s²、角速度噪声标准差 0.005 rad/s。

## 输出与风险

新配置、缓存、权重和评估结果使用独立的 `artifacts/ego_xreal_joint_9class`
目录，不覆盖原始 EgoCHARM 复现或 Xreal 摘戴实验。

主要风险是设备与标签完全相关：七个活动只来自 Aria，两个摘戴类别只来自
Xreal。坐标统一和增强只能缓解设备捷径，不能消除。稳定 Xreal 的事件误报率
作为必要的诊断指标；最终要可靠证明动作学习，仍需要补采 Xreal 的非事件活动
或 Aria 的摘戴样本。
